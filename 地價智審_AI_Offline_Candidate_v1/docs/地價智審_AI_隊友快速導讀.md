1. 我們在解決什麼問題
「地價智審 AI」是一套協助地政人員審查「土地徵收補償市價查估」案件的系統。估價師交出來的查估書表，裡面有大量欄位、計算式、跨表格數字，人工逐一核對非常耗時，也容易漏看錯誤。我們把這個核對過程自動化。
核心概念：使用者輸入案件資訊／上傳查估書表 → 系統擷取欄位 → 自動補齊官方資料 → 規則引擎重新核算 → 跨表比對 → 找出錯誤或不一致 → 提供人工覆核 → 產出結果與PDF。
2. 系統主要流程
建立案件　→　上傳／選擇查估書表　→　欄位擷取　→　人工確認低信心欄位　→　自動蒐集官方資料　→　Rule／Grade／Calculation 計算　→　完成查估書表　→　跨表與欄位一致性檢查　→　審查結果　→　PDF／人工覆核
目前系統可以現場展示兩種案例：
Golden Case（正常案例）：欄位與計算全數正確，系統不會產生「假警報」。
Error Case（錯誤案例）：刻意植入3個常見錯誤（等級誤判、修正率算錯、跨表不一致），系統能正確抓出來，並說明問題出在哪裡、會影響到哪些下游數字。

4. AI 到底負責什麼
這一點請特別記住，上台被問到的時候不要說錯：不是「AI自己判斷估價正不正確」。
正確的分工是：
官方資料 ＋ 規則引擎（Rule／Grade／Calculation）＋ 跨表比對　→　負責判斷欄位與計算是否正確、一致。
AI／LLM　→　負責把已經算好的結果，整理、解釋成白話文，方便審查人員閱讀。
如果官方資料不足，系統不會亂猜，會誠實標示「UNKNOWN」或「需要人工確認」。
「規則引擎決定結果，AI 解釋結果。」

7. 上台要記住的三件事
① 我們不是讓AI亂猜　核心結果來自「官方資料 ＋ 規則引擎」，不是AI自由發揮。
② 系統價值是自動核算與抓錯　包含欄位錯誤、計算錯誤、跨表不一致，這是最大的賣點。
③ 資料不足時不假裝知道　會誠實標示 UNKNOWN／需要人工確認，絕不亂補數字。
