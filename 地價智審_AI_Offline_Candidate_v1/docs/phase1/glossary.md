# Phase 1 — Glossary（名詞釋義）

所有釋義均引自作業手冊或查估書表範本原文，並標註出處；無法在 Sources 中找到逐字
定義者，標示為【合理推論】並說明推論依據，不得視為官方逐字定義。

---

### 地價區段（Land Price Segment）

劃分地價區段時，應攜帶地籍圖及地價區段勘查表實地勘查，原則以鄉（鎮、市、區）為
單位，斟酌地價之差異、當地土地使用管制、交通運輸、自然條件、土地改良、公共建設、
特殊設施、環境污染、工商活動、房屋建築現況、土地利用現況及其他影響地價因素，將
地價相近、地段相連、情況相同或相近之土地劃為同一地價區段。

- 分類：官方明確要求（法定用詞）
- 出處：作業手冊「參、三、劃分或修正地價區段，並繪製地價區段圖」
- Golden Case 對照：金山區 P002-00（第二種商業區）

### 比準地（Base Parcel / Reference Parcel）

指地價區段內具代表性，以作為查估地價區段內各宗土地市價比較基準之宗地；或作為
查估公共設施保留地毗鄰非公共設施保留地區段地價之宗地。

- 分類：官方明確要求（土地徵收補償市價查估辦法第2條法定定義）
- 出處：作業手冊附錄「土地徵收補償市價查估辦法」第二條第二款
- Golden Case 對照：金山區金美段489地號

### 比較標的（Comparison Subject / Sales Comparable）

用以與比準地進行比較法試算之買賣實例（成交案例）。表4「比較法調查估價表」以
比較標的之土地正常單價為起點，依序調整價格日期、區域因素、個別因素後，推算出
比準地之比較價格。

- 分類：官方明確要求（表單法定用詞，見查估書表範本表4欄位名稱）
- 出處：查估書表範本 表4；作業手冊「伍、六、比較法調查估價表」
- Golden Case 對照：實例編號1，新北市金山區溫泉段218地號

### 區域因素（Regional Factors）

影響整個地價區段地價水準之因素，涵蓋土地使用管制、交通運輸、自然條件、公共建設、
環境污染、工商活動、特殊設施、其他影響因素等主要項目，於表5-2「影響地價區域因素
分析明細表」中逐項評定優劣等級與修正百分比。

- 分類：官方明確要求
- 出處：作業手冊「伍、五、影響地價區域因素分析明細表」；命題文件背景說明
- 對應主要項目（依查估書表範本表5-2欄位）：土地使用管制(1)、交通運輸(2)、
  自然條件(3)、公共建設(4)、特殊設施(5)、環境污染(6)、工商活動(7)、其他影響
  因素(8)

### 個別因素（Individual Factors）

影響特定宗地（比準地或比較標的）相對於區段內其他土地之地價差異因素，涵蓋宗地
條件、道路條件、接近條件、周邊環境條件、行政條件等，於表4「比較法調查估價表」
中依「影響地價個別因素評價基準明細表」逐項評定優劣等級與差異率。

- 分類：官方明確要求
- 出處：作業手冊「伍、六、比較法調查估價表」；評價基準明細表範例（個別因素部分）
- 對應主要項目（依查估書表範本表4欄位）：宗地條件(1)、道路條件(2)、接近條件(3)、
  周邊環境條件(4)、行政條件(5)、其他(6)

### 優劣等級（Grade / Quality Ranking）

依評價基準明細表所訂之分級方式，將區域因素或個別因素之各細項評定為「優」至「劣」
之等級。官方認可之分級方式共5種：2級（優/劣）、3級（優/普通/劣）、5級（優/稍優/
普通/稍劣/劣）、7級（極優~極劣）、9級（超極優~超極劣，9級以上由地方政府自行決定
細項）。金山區商業用地範例採5級制，代碼1=優、2=稍優、3=普通、4=稍劣、5=劣。

- 分類：官方明確要求
- 出處：作業手冊「伍、五、（七）...評價基準明細表注意事項」第2點（p.48-49）
- 重要限制：優劣等級之判定不可由AI/LLM自行認定，須依評價基準明細表對照判定
  （此為 Rule Engine 須 deterministic 的直接業務依據）

### 修正率 / 修正百分比（Adjustment Rate / Adjustment Percentage）

依優劣等級對應評價基準明細表所訂級距，計算出之地價調整百分比。區域因素之修正率
於表5-2逐項計算後加總為「影響地價區域因素總修正數」；個別因素之修正率（差異率）
於表4逐項計算後併入試算價格之調整。修正百分比原則上依基準明細表級距填載，若因
個案特殊情況需調整，須於備註欄敘明理由，且不得超出基準表所定最大影響範圍。

- 分類：官方明確要求
- 出處：作業手冊「伍、五、(六)...注意事項」第3點；「(七)」第3點（p.47-49）

### 評價基準明細表（Evaluation Criteria Table）

由直轄市、縣（市）政府或地政機關依鄉（鎮、市、區）為單位訂定之對照表，分為
「影響地價區域因素評價基準明細表」與「影響地價個別因素評價基準明細表」兩份，
針對特定行政區、特定用地類別，列出各評價細項的優劣等級劃分原則與對應之價格
修正率（含比準地與比較標的間、以及不同等級間之級距換算表）。

- 分類：官方明確要求
- 出處：作業手冊「伍、五、(七)」；評價基準明細表範例.pdf 全文
- 重要限制（本次競賽）：賽前僅提供金山區商業用地一份範例；決賽當日將提供對應
  當次考題區段的另一組基準明細表，用地類別可能不同，系統設計不可寫死金山區
  範例之級距數字（詳 `open_questions.md` C-1）

### 影響地價區域因素總修正數（Total Regional Adjustment）

各比較標的地價區段，依各主要修正項目小計之修正數（修正百分比）計算與比準地
區段間單項修正率後，將各單項修正率相加推算出之區域因素總修正數；此數值須帶入
表4「區域因素調整」欄，並須與表5-2本身之計算結果一致（此為官方審查checklist之
明確檢查項）。

- 分類：官方明確要求
- 出處：作業手冊「伍、五、(六)3.(3)(4)」（p.48）；「柒、七、審查重點vi/vii」
  （p.11-12）

### 比較法（Sales Comparison Approach）

不動產估價方法之一，以比較標的（買賣實例）之正常單價為基礎，依序進行價格日期
調整、區域因素調整、個別因素調整後，推算出比準地之比較價格；若有多筆比較標的，
依「調整百分率絕對值加總」反映之價格形成因素相近程度分配權重，加權平均後得出
比準地比較價格。

- 分類：官方明確要求
- 出處：作業手冊「伍、六、比較法調查估價表」（p.50-53）；查估書表範本 表4

### 查估書表（Appraisal Forms）

土地徵收補償市價查估過程中，依土地徵收補償市價查估辦法規定應填製之一系列標準
表單，本次競賽聚焦其中三張：表1地價區段勘查表、表5-2影響地價區域因素分析明細表、
表4比較法調查估價表。完整書表體系尚包含買賣實例調查估價表、收益法調查估價表、
徵收土地宗地市價估計表／評議表／清冊、比準地地價估計表等（本次競賽範圍外，
詳 `open_questions.md` D-5）。

- 分類：官方明確要求
- 出處：作業手冊目錄「伍、土地徵收補償市價查估書表填表說明」；命題文件

## 補充詞彙（非命題文件原始10項要求，但為理解 Sources 所必要，一併收錄）

### 試算價格（Trial Price）

表4中，單一比較標的經價格日期調整、區域因素調整、個別因素調整後所得之推算單價；
若有多筆比較標的，各自之試算價格再依權重加權平均，得出「比準地比較價格」。

- 分類：官方明確要求（表單法定欄位）
- 出處：查估書表範本 表4

### 調整百分率絕對值加總（Sum of Absolute Adjustment Percentages）

表4中，將個別因素調整表中各細項差異率取絕對值後加總之數值，作為判斷「價格形成
因素之相近程度」（優/較高/普通/較低）進而決定各比較標的權重之依據；官方僅提供
舉例級距（7%/10%/15%對應50%/30%/20%權重），非固定公式（詳 `open_questions.md`
B-2）。

- 分類：官方明確要求（欄位存在與邏輯方向）／官方建議（舉例級距數字本身僅為範例）
- 出處：作業手冊「伍、六、(十一)」（p.52-53）

### 尾數計算規則（Rounding Rules）

土地徵收補償市價查估中至少存在兩種不同的尾數處理規則：①比準地地價／宗地市價
本身，依金額級距採**分級無條件進位**；②表4比準地比較價格（試算價格加權結果），
採**四捨五入**至個位數。兩者不可混用（詳 `official_requirements.md` 第15節）。

- 分類：官方明確要求
- 出處：作業手冊 p.9-10（①）、p.52-53（②）
