# Phase 1 — Competition I/O Spec

本文件整理「競賽輸入 → 處理 → 預期輸出」，並區分 Confirmed／Likely／Unknown。
對應詳細證據見 `evidence_matrix.md`。

## 圖示：Confirmed / Likely / Unknown 定義

- **Confirmed**：有官方文件、官方通知信或工作坊逐字稿明確陳述，分類屬【官方明確
  要求】。
- **Likely**：官方以「建議」「鼓勵」「舉例」語氣提及，或官方明確要求存在但細節
  仍待確認，分類屬【官方建議】【講者舉例】或部分確認之【官方明確要求】。
- **Unknown**：Sources 中未提及或明確表示「屆時才公布」，分類屬【待確認】。
